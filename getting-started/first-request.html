    Первый запрос

    Найдём свободные автомобили в Абиджане на выходные.

    Запрос

    curl "https://sandbox.autorent.example/v2/vehicles?city=abidjan&from=2026-11-07&to=2026-11-09" \
  -H "Authorization: Bearer ar_test_9f2c7d1e4b8a4c0f9e3d"

    Ответ

    {
  "data": [
    {
      "id": "veh_1042",
      "brand": "Toyota",
      "model": "Corolla",
      "year": 2023,
      "category": "sedan",
      "price_per_day": 25000,
      "currency": "XOF",
      "available": true
    }
  ],
  "meta": {
    "page": 1,
    "per_page": 20,
    "total": 1
  }
}

    Пример полного ответа можно скачать: vehicles-sample.json.
