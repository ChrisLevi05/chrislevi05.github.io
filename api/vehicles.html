    Автомобили

    GET/vehiclesСписок автомобилей с фильтрами

    Параметры запроса

    ПараметрТипОписание
    citystringГород выдачи (abidjan, yamoussoukro…)
    from, todateДаты аренды (YYYY-MM-DD)
    categorystringeconomy, sedan, suv, minibus
    pageintegerНомер страницы, по умолчанию 1

    Пример ответа

    {
  "id": "veh_2077",
  "brand": "Hyundai",
  "model": "Tucson",
  "category": "suv",
  "seats": 5,
  "transmission": "automatic",
  "price_per_day": 45000,
  "currency": "XOF",
  "available": true
}
    GET/vehicles/{{id}}Подробная карточка автомобиля

    Возвращает те же поля, плюс фотографии, условия депозита и список доп. опций.
