  "booking_id": "bkg_9001",
  "method": "mobile_money",
  "provider": "orange_money",
  "amount": 52000,
  "currency": "XOF"
}

    Способы оплаты

    МетодЗначение methodКомментарий
    Банковская картаcardVisa, Mastercard
    Mobile Moneymobile_moneyOrange Money, MTN, Wave
