    Бронирования

    Жизненный цикл бронирования

    POST/bookingsСоздать бронирование

    Тело запроса

    {
  "vehicle_id": "veh_1042",
  "customer_id": "cus_331",
  "pickup_date": "2026-11-07",
  "return_date": "2026-11-09",
  "options": [
    "child_seat"
  ]
}

    Ответ (201 Created)

    {
  "id": "bkg_9001",
  "status": "pending",
  "total": 52000,
  "currency": "XOF",
  "expires_at": "2026-11-01T12:00:00Z"
}
    Бронирование в статусе pending живёт 30 минут. Если оплата не поступила, оно отменяется автоматически.
    DELETE/bookings/{{id}}Отменить бронирование

    Бесплатная отмена — не позднее чем за 24 часа до выдачи автомобиля.
