    Клиенты

    POST/customersЗарегистрировать клиента

    Тело запроса

    {
  "first_name": "Awa",
  "last_name": "Koné",
  "email": "awa@example.com",
  "phone": "+225-0700000000",
  "driver_license": {
    "number": "CI-123456",
    "expires": "2029-05-01"
  }
}

    Правила проверки

    • Возраст водителя — не менее 21 года.
    • Водительское удостоверение действует на всё время аренды.
    • E-mail уникален в пределах партнёра.
    GET/customers/{{id}}Данные клиента

    Персональные данные возвращаются только ключам с областью customers:read.
