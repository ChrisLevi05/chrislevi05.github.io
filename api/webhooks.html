    Вебхуки

    Вебхук — HTTP-запрос, который AutoRent отправляет на ваш сервер при наступлении события.

    POST/webhooksСоздать подписку
    {
  "url": "https://partner.example/hooks/autorent",
  "events": [
    "booking.confirmed",
    "payment.succeeded"
  ]
}

    События

    СобытиеКогда отправляется
    booking.confirmedБронирование оплачено и подтверждено
    booking.cancelledБронирование отменено
    payment.succeededПлатёж прошёл успешно
    payment.refundedСредства возвращены клиенту

    Проверка подписи

    Каждый запрос содержит заголовок X-AutoRent-Signature — HMAC-SHA256 от тела запроса с вашим секретом. Отклоняйте запросы с неверной подписью.

    import hmac, hashlib

def is_valid(body: bytes, signature: str, secret: str) -> bool:
    expected = hmac.new(secret.encode(), body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature)
