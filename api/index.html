    Справочник API

    Сводный список эндпоинтов версии v2.

    Автомобили

    GET/vehiclesСписок автомобилей
    GET/vehicles/{{id}}Карточка автомобиля

    Бронирования

    POST/bookingsСоздать бронирование
    GET/bookings/{{id}}Получить бронирование
    DELETE/bookings/{{id}}Отменить бронирование

    Клиенты

    POST/customersЗарегистрировать клиента
    GET/customers/{{id}}Данные клиента

    Платежи

    POST/paymentsПровести оплату
    POST/payments/{{id}}/refundВернуть платёж

    Вебхуки

    POST/webhooksПодписаться на события
    DELETE/webhooks/{{id}}Удалить подписку

    Машиночитаемая спецификация: openapi.json.
