    Коды ошибок

    Все ошибки возвращаются в едином формате.

    {
  "error": {
    "code": "vehicle_unavailable",
    "message": "Автомобиль занят на выбранные даты",
    "status": 409
  }
}
    HTTPКод ошибкиЧто делать
    400invalid_requestПроверить параметры запроса
    401unauthorizedПроверить API-ключ
    403forbiddenДобавить нужную область доступа ключу
    404not_foundПроверить идентификатор ресурса
    409vehicle_unavailableВыбрать другой автомобиль или даты
    429rate_limitedПодождать время из Retry-After
    500server_errorПовторить запрос позже
    Повторяйте запрос автоматически только при кодах 429 и 5xx, с увеличивающейся паузой.
