    Пагинация

    Списки возвращаются страницами по 20 элементов (максимум 100).

    curl "https://api.autorent.example/v2/vehicles?page=2&per_page=50" -H "Authorization: Bearer $AUTORENT_KEY"

    Блок meta в ответе

    {
  "meta": {
    "page": 2,
    "per_page": 50,
    "total": 134,
    "total_pages": 3
  }
}

    Перебор всех страниц

    async function fetchAll(url, key) {
  let page = 1, all = [];
  while (true) {
    const res = await fetch(`${url}?page=${page}`, { headers: { Authorization: `Bearer ${key}` } });
    const json = await res.json();
    all = all.concat(json.data);
    if (page >= json.meta.total_pages) break;
    page++;
  }
  return all;
}
