    AutoRent API

    AutoRent API — REST API вымышленного сервиса аренды автомобилей. Через него партнёры получают каталог машин, создают бронирования, регистрируют клиентов и принимают оплату.

    Архитектура

    Основные возможности

    Автомобили

    Каталог, фильтры, доступность по датам.

    Бронирования

    Создание, подтверждение и отмена аренды.

    Платежи

    Оплата, возврат депозита, статусы.

    Вебхуки

    Уведомления о событиях в реальном времени.

    Базовый адрес

    https://api.autorent.example/v2

    Все ответы приходят в формате JSON (UTF-8). Полная спецификация в формате OpenAPI: openapi.json.

    С чего начать

    1. Получите API-ключ
    2. Разберитесь с аутентификацией
    3. Отправьте первый запрос
